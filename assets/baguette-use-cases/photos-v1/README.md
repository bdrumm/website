# Finished product lifestyle renders

Generated September 13, 2026 with the **built-in image generation tool**, using the current V3.19 `closed.jpg`, `open.jpg` and `strap.jpg` CAD views as product references. All 49 finished assets are saved in this directory as 1536 × 1024 JPEGs at quality 86. The original generated PNGs remain in the tool's output directory.

The seven scenes are `carry`, `purse`, `essentials`, `rain`, `picnic`, `travel` and `backpacking`. Each has an `ivory`, `graphite`, `forest`, `clay`, `cobalt`, `matte-silver` and `yellow` variant, named `scene-finish.jpg`.

The photos show Pro Max proportions. The original Ivory scenes were checked against the CAD references for product proportions, the middle assembly seam, two compact latches, the original two projecting strap eyes on the same edge, open-case construction, and shoulder suspension. Each other finish was generated as a color-only edit of its Ivory scene. Matte Silver uses a diffuse, low-gloss surface; Yellow is a warm sunflower color. These are generated lifestyle illustrations, not photographs of manufactured or tested products.

[provenance.json](provenance.json) contains the exact final prompt for every image, source-reference SHA-256 hashes, original generator output names, saved JPEG hashes and file sizes.

The public page switches complete image files when the finish changes. It does not overlay CAD, composite image layers, apply a CSS recoloring filter, or animate these images. The separate top CAD viewer continues to show the selected size and finish. Technical feature photographs remain the original CAD exports in Ivory or annotation colors.
