# Pebbl Switch screens

Unmodified 480 × 800 LVGL / SDL simulator captures from the rotary-display project.

- `main.png`: `panel/review/live-zones-2026-09-13/main.png` — grouped Living Room and Kitchen controls, with Bright / Dimmed / Off shortcuts for the mock home.
- `room.png`: `panel/review/minimal-switch-2026-09-13/room.png` — individual Living Room lights, matching the monochrome Switch design.
- UI implementation: `panel/libraries/panelui/src/panel_switch.c`.

All light names, counts and brightness values shown here are simulator sample data. These are screen captures, not working home controls. The enclosure viewer maps the captures onto the active display area, without modifying the CAD geometry. Older 5-inch archive models retain their blank screen.
