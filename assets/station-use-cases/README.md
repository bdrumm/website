# Station use-case images

Created September 12, 2026 using the built-in image generation tool. Five separate prompts, one output per scene.

These are AI-generated use-case concepts adapted from official Waveshare product photographs. They illustrate the custom Station screen design; they are not photographs of a finished commercial product. The dock is a concept accessory. The clean enclosure omits the keychain/strap attachment, projecting side controls and speaker grille as requested.

## Product references

The official ESP32-S3-Touch-AMOLED-1.75C dimensional drawing specifies Ø55.00 mm × 15.05 mm for the body, Ø48.96 mm for the black/glass region and Ø43.76 mm for the active display. The display resolution is 466 × 466. These dimensions guided the prompts and supersede the earlier dimensions in the page copy.
